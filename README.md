# 🌾 KisanSetu  
### Bridging Farmers, Customers & Delivery in One Smart Platform 🚜📦

KisanSetu is an Android application designed to directly connect **Farmers**, **Customers**, and **Delivery Partners** through a seamless digital marketplace.  
The platform removes middlemen, ensures fair pricing, and provides fresh farm products directly to consumers using smart digital solutions.

## ✨ Key Features

### 👨‍🌾 Farmer Module
- Register / Login securely  
- Add farm products with images, price & quantity  
- Manage orders easily  
- Track earnings and sales  
- Detect plant diseases using AI image analysis  
- Compare crop prices with mandi market rates  

### 🛒 Customer Module
- Browse fresh vegetables, fruits & products  
- Add to cart & place orders  
- Save addresses  
- Live order updates  

### 🚚 Delivery Partner Module
- Accept deliveries  
- View pickup & drop locations  
- Update delivery status  
- Manage completed orders  

## 🤖 AI Smart Features

### 📈 Price Prediction & Comparison
- Predict crop prices using market trends  
- Compare direct selling price with mandi prices  
- Help farmers choose better selling options  

### 🌿 Plant Disease Detection
- Detect leaf diseases using AI image recognition  
- Suggest early prevention tips  
- Reduce crop loss and improve quality
